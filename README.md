# TaiMEN GAMES

TaiMENのゲームで使うAI判定用プロンプト・ルール・使い方を公開する静的サポートサイト。
判定は利用者自身のChatGPTで行います。API・APIキー・サイトの会員登録は不要です。

## 構成

- `index.html`：トップ・ゲーム一覧
- `games/in-bouron/index.html`：In暴論の案内とプロンプト全文（現在は準備中）
- `assets/style.css`：共通デザイン
- `assets/prompt.js`：全文コピーと失敗時の手動選択
- `.nojekyll`：ビルド不要で静的ファイルを配信

## プロンプトを公開・更新する

1. 正式なゲーム名、ルール、判定用プロンプトを確認します。GPTsの知識ファイルに必須情報がある場合は、必要な内容をプロンプト全文に統合してください。採点基準を推測して追加しないでください。
2. ゲームページの `textarea id="prompt-text"` の開始・終了タグの間に、正式な全文を書きます。HTMLとして `&` は `&amp;`、`<` は `&lt;` に置き換えます。コピー時は元の文字に戻ります。開始・終了タグ直後に不要な改行・空白を追加しないでください。
3. バージョンと更新日（例：v1.0 / 2026-10-17）を記入します。必要な入力や開始手順を正式ルールに合わせます。
4. コピー用buttonの `disabled` を外し、文言を「判定用プロンプトをコピー」にします。「準備中」と未公開の説明・placeholderを更新します。トップの準備中表示と案内も更新します。
5. 通常のChatGPTの新しいチャットで、全文を1回貼り付け、開始と判定が成立するか確認します。写真が必要なゲームでは写真送信も確認します。
6. 下の動作確認を行い、GitHubへ変更を反映します。

全文の更新元はゲームページ内のtextareaだけです。外部ファイルの取得やJavaScriptが失敗しても、公開した全文を手動で選択できます。

## ゲームを追加する

`games/in-bouron/` を `games/新しい英数字の識別子/` へ複製し、タイトル・説明・全文・状態を更新します。トップのカードを追加し、ゲーム数表示も更新します。各ページで共通CSSとJSは `../../assets/` を参照します。準備中はコピーを無効のままにします。

## GitHub Pages

リポジトリの Settings → Pages → Build and deployment で Source を **Deploy from a branch**、Branch を **main / (root)** にして保存します。反映まで数分かかる場合があります。

公開先：https://friver1985.github.io/TaiMEN-GAMES/

In暴論の案内・将来の印刷用QRコードの宛先：https://friver1985.github.io/TaiMEN-GAMES/games/in-bouron/

全内部リンクは相対パスです。GitHub Pagesの `/TaiMEN-GAMES/` 配下と、同じディレクトリ構成のローカル環境で動きます。ビルド・依存ライブラリ・外部フォントはありません。

既に印刷されたGPTs直リンクQRコードは、このサイトへ自動的に切り替わりません。

## 動作確認

- スマホ幅で説明・ボタン・全文が読め、横スクロールが出ないこと。
- 公開済みプロンプトをコピーし、全文・改行・末尾まで一致すること。
- クリップボードの許可を拒否した場合、失敗案内と全文選択が出ること。
- JavaScript無効時にも全文を選択できること。
- ChatGPTリンク、トップとゲーム間のリンク、CSSとJSを公開URLで確認すること。
- 準備中ページには正式なプロンプトがなく、コピーが無効であること。
